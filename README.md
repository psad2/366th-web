# V366 Air Force-inspired site

This version follows the reference site's broad public-facing recruitment structure: large photographic hero, oversized editorial typography, strong CTA sections, mission/organization blocks and a recruitment close.

It uses an original V366 visual identity with ranger green, olive, tan and cream rather than reproducing the Air Force site's branding.

Replace the image URLs with your own aircraft/wing photography and replace the Join links with your Discord/application URL.
